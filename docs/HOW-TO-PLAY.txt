ENTER THE GUNGEON ONLINE CO-OP MOD 1.0 (beta)

INSTALL (close the game first, pick ONE way)

  Option A, the installer:
    Double-click "Install Gungeon Online.bat". It finds your game by itself.
    If Windows says "Windows protected your PC": More info, then Run anyway.

  Option B, by hand:
    Open your game folder (the one with EtG.exe).
      Steam: right-click the game, Manage, Browse local files.
      GOG Galaxy: the game, settings icon, Manage installation, Show folder.
    Copy everything inside the "files" folder of this download into it.

  Check: start the game and pause. You should see PLAY ONLINE.

PLAY

  1. Pause and pick PLAY ONLINE (or hold Back + Start, or press F8).
  2. One player picks Host. The invite code is copied for you: send it.
  3. The other player copies the code and picks Join.
  4. Both pick a character in the Breach. The host walks into the Gungeon.

  Both players need the same version of the mod.
  If the connection drops, the run waits for you and you reconnect by yourself.
  Problem? Settings, Help, Save report, then open an issue on GitHub:
  https://github.com/Hero88go/EnterTheGungeonOnlineCoOpMod/issues
